## 二、Tailwind CSS v4 接入

v4 最大的变化：**不再有 `tailwind.config.js`，改用 CSS 第一公民**。项目里零配置文件，全靠一行导入：

`postcss.config.mjs`
```js
const config = {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};
export default config;
```

`app/globals.css` 顶部一行即可：
```css
@import "tailwindcss";
```

接下来在 CSS 里用 `@theme` 定义设计令牌（本项目「纸感编辑风」的色板与字体）：

```css
@theme {
  --color-paper: #faf7f2;       /* 纸张底色 */
  --color-ink: #262220;         /* 墨色 */
  --color-accent: #b8422f;      /* 点缀红（印章色） */
  --color-night: #1b1917;       /* 深色底 */
  --font-serif: "Noto Serif SC", serif;      /* 中文衬线标题 */
  --font-sans: "Noto Sans SC", sans-serif;   /* 中文黑体正文 */
  --font-mono: "IBM Plex Mono", monospace;   /* 等宽数据感 */
}
```

> 用了 `@theme` 定义后，Tailwind 自动生成 `bg-paper`、`text-ink`、`font-serif` 这类工具类。**改一处色值，全站生效**，这就是设计令牌的意义。

## 三、字体方案：@fontsource（国内必看）

中文博客最坑的点：**别在 Next 里用 `next/font/google` 引 Google Fonts**——国内网络直接卡死或超时。

本项目的做法：字体全部走 **npm 包 `@fontsource/*`**，随依赖安装下载，构建时本地打包，不请求任何外部字体 CDN。

`app/[locale]/layout.tsx`
```tsx
import "@fontsource/noto-serif-sc/500.css";   // 衬线 中/粗/黑
import "@fontsource/noto-serif-sc/700.css";
import "@fontsource/noto-serif-sc/900.css";
import "@fontsource/noto-sans-sc/400.css";    // 黑体
import "@fontsource/ibm-plex-mono/400.css";   // 等宽（编号/日期/标签用）
```

三套字体职责分明，呼应「纸感编辑风」：
- **Noto Serif SC** → 标题（`font-serif`），有书卷气；
- **Noto Sans SC** → 正文（`font-sans`），清晰耐读；
- **IBM Plex Mono** → 日期、编号、tag（`font-mono`），编辑/排版感。

## 四、国际化插件接入（next-intl）

`next.config.ts`
```ts
import createNextIntlPlugin from "next-intl/plugin";
const withNextIntl = createNextIntlPlugin("./i18n/request.ts");
export default withNextIntl(nextConfig);
```

`i18n/request.ts` 是语言解析入口（第 6 节细讲），插件负责在编译期 hook 进 App Router，让 `[locale]` 动态段可用。

## 五、图片域名白名单（images.remotePatterns）

Next 的 `<Image>` 有 **图片优化服务**，默认只信任本域名图片。引用外部图床必须在 `next.config.ts` 声明：

```ts
images: {
  remotePatterns: [
    { protocol: "https", hostname: "images.unsplash.com" },  // 封面占位图
    { protocol: "http", hostname: "piclink.puxiaoshuai.top" }, // 生产图床
  ],
},
```

> 新图床域名上线前**记得加白名单**，否则 `next/image` 会报 `hostname not configured`。这是接手项目最常见的坑之一。

## 六、开发体验：LocatorJS

Next 16 默认用 Turbopack 打包，配置里给 tsx/jsx 注入编译期标记，配合浏览器里的 Option+Click 直接跳到源码：

```ts
turbopack: {
  rules: {
    "**/*.{tsx,jsx}": {
      loaders: [{ loader: "@locator/webpack-loader", options: { env: "development" } }],
    },
  },
},
```

只在 dev 生效，不影响生产构建。

## 七、ESLint

Next 16 自带新式扁平配置（flat config），继承官方两条规则集：

`eslint.config.mjs`
```js
import nextVitals from "eslint-config-next/core-web-vitals";
import nextTs from "eslint-config-next/typescript";
const eslintConfig = defineConfig([...nextVitals, ...nextTs, globalIgnores([...])]);
```

## 八、本节小结

- **Tailwind v4**：无配置文件，`@import "tailwindcss"` + `@theme` 设计令牌。
- **字体**：`@fontsource` npm 包，绕过 Google Fonts，国内部署不卡。
- **国际化**：`createNextIntlPlugin` 一行接入。
- **图片**：外部图床必须进 `remotePatterns` 白名单。
- **开发工具**：Turbopack 规则注入 LocatorJS，Option+Click 跳源码。
