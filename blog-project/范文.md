## 十四、Mermaid 图表（时序图 / 流程图）

用 ` ```mermaid ` 代码块即可嵌入时序图、流程图、类图、ER 图等，渲染成 SVG：

```mermaid
sequenceDiagram
    participant 你 as 读者
    participant 站 as 博客
    你->>站: 打开文章页
    站-->>你: 渲染 Mermaid 时序图
    你->>站: 阅读 / 翻页
    站-->>你: 返回正文内容
```

```mermaid
flowchart LR
    A[写 Markdown] --> B{含 mermaid?}
    B -- 是 --> C[编译为 Mermaid 组件]
    B -- 否 --> D[普通排版]
    C --> E[客户端渲染 SVG]
    D --> E
```
